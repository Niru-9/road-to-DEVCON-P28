# Source files used

The project was assembled from the uploaded files:

- `ai_studio_code.txt` → `package.json`
- `ai_studio_code (2).txt` → `tsconfig.json`
- `ai_studio_code.ts` → `tailwind.config.ts`
- `ai_studio_code.css` → `app/globals.css`
- `ai_studio_code (3).txt` → `app/layout.tsx`
- `ai_studio_code (5).txt` → `app/page.tsx` (the more complete 762-line page variant)
- `postcss.config.mjs` was added because the supplied folder tree references it but no matching config file was uploaded.
- `README.md`, `.gitignore`, `.env.example`, and the OpenCode integration brief were added for handoff and safe adaptation.

Duplicate copies of the Tailwind config and CSS were consolidated. The shorter 641-line page variant was not used because the 762-line variant contains the fuller donation drawer.
